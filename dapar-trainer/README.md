# מתאמנים לדפ״ר

אתר לתרגול מבחן הדפ״ר (דירוג פסיכוטכני ראשוני). האתר כולו בעברית ומימין לשמאל, ועובד במחשב ובטלפון. אין שרת ואין התחברות: כל הנתונים נשמרים בדפדפן (`localStorage`).

## מה יש באתר

- **ארבעה נושאים:** שאלות מילוליות, הבנת הוראות, שאלות כמותיות, ומטריצות וצורות (מצוירות ב-SVG).
- **מחוללים:** שאלות כמותיות ומטריצות נוצרות אוטומטית, כך שהתרגול לא נגמר.
- **מצבי תרגול:** לפי נושא, מעורב, סימולציית מבחן ומאגר טעויות.
- **רמות קושי:** קל, בינוני, קשה, מעורב, או מצב אדפטיבי.
- **טיימר לשאלה:** בלי טיימר, 30, 45, 60 או 90 שניות, או זמן מותאם אישית.
- **דשבורד:** אחוזי הצלחה לפי נושא ולפי רמת קושי, גרף התקדמות, המלצה מה לתרגל והיסטוריית מבחנים.
- **גיימיפיקציה:** נקודות XP, רמות בדרגות צבאיות, רצף ימי תרגול ו-14 תגים.
- **מקלדת:** המקשים `1`–`4` בוחרים תשובה, ו-`Enter` עובר לשאלה הבאה.

## הרצה

צריך Node.js בגרסה 20 ומעלה.

```bash
npm install
```

```bash
npm run dev
```

האתר יעלה בכתובת שמוצגת בטרמינל (בדרך כלל `http://localhost:5173`).

פקודות נוספות:

| פקודה | מה היא עושה |
|---|---|
| `npm test` | מריצה את כל הבדיקות (אימות המאגרים והמחוללים) |
| `npm run build` | בונה גרסה סופית לתיקייה `dist/` |
| `npm run preview` | מציגה את הגרסה הסופית |
| `npx vite-node scripts/sample-questions.ts` | מדפיסה דוגמאות של שאלות מחוללות, לבדיקת ניסוח |
| `npx vite-node scripts/gen-matrices.ts` | מייצרת מחדש את מאגר המטריצות הקבוע |

> **במחשב הזה** Node מותקן כגרסה ניידת. לפני ההרצה צריך להוסיף אותו ל-PATH:
> ```bash
> $env:Path = "$env:LOCALAPPDATA\nodejs-portable\node-v22.11.0-win-x64;$env:Path"
> ```

הגרסה הסופית (`dist/`) היא אתר סטטי, ואפשר להעלות אותה לכל אחסון כמו Netlify או GitHub Pages. הניווט מבוסס על `#`, כך שלא צריך הגדרות שרת.

## מבנה התיקיות

```
src/
├─ app/            ניתוב ומבנה הדף (כותרת וניווט)
├─ pages/          העמודים: בית, תרגול, סימולציה, טעויות, התקדמות
├─ features/       לוגיקה של מסכים: מנוע התרגול, בניית מבחן
├─ components/     רכיבים לשימוש חוזר: שאלה, תשובות, טיימר, גרפים, מטריצות
├─ engine/         בלי React: בחירת שאלות, אדפטיבי, ציונים, XP ותגים, סטטיסטיקה
├─ questions/
│  ├─ data/        מאגרי השאלות (JSON, קובץ לכל נושא)
│  ├─ generators/  מחוללי שאלות
│  ├─ matrices/    מודל המטריצות, המחולל והפותר
│  ├─ solvers/     מחשבון ביטויים, סדרות ופותר להבנת הוראות
│  ├─ types.ts     מודל הנתונים
│  └─ validate.ts  בדיקת תקינות של שאלה
├─ config/         הגדרות הסימולציה
└─ store/          שמירת התקדמות והגדרות ב-localStorage
tests/             בדיקות Vitest
```

## איך מוסיפים שאלות

מוסיפים אובייקט לקובץ ה-JSON של הנושא ב-`src/questions/data/`, ואז מריצים `npm test`. הבדיקות יגידו אם משהו לא תקין.

שדות משותפים לכל השאלות:

| שדה | תיאור |
|---|---|
| `id` | מזהה ייחודי, למשל `verbal-analogy-14`. אסור לשנות אותו אחרי פרסום, כי מאגר הטעויות נשען עליו |
| `subtopic` | תת-נושא (הרשימה המלאה ב-`src/questions/types.ts`) |
| `difficulty` | `easy` / `medium` / `hard` |
| `prompt` | טקסט, או מערך של שורות. שורה שכולה מספרים (למשל סדרה) מוצגת אוטומטית משמאל לימין |
| `choices` | בדיוק 4 תשובות, לפי הסדר a, b, c, d. הסדר מתערבב בזמן ההצגה |
| `correct` | `a` / `b` / `c` / `d` |
| `explanation` | הסבר מפורט לפתרון |
| `needsReview` | `true` מוציא את השאלה מהתרגול. מוסיפים גם `reviewNote` עם הסיבה |

### שאלה מילולית (`verbal.json`)

```json
{
  "id": "verbal-synonym-10", "subtopic": "synonym", "difficulty": "medium",
  "prompt": "איזו מילה קרובה ביותר במשמעותה למילה 'אמיץ'?",
  "choices": ["פחדן", "נועז", "חכם", "שקט"], "correct": "b",
  "explanation": "'אמיץ' ו'נועז' מתארים מי שלא נרתע מסכנה..."
}
```

### שאלה כמותית (`quantitative.json`)

חובה להוסיף `verify`, כדי שהבדיקות יחשבו את התשובה מחדש:

```json
{
  "id": "quant-pct-12", "subtopic": "percent-ratio", "difficulty": "easy",
  "prompt": "כמה הם 15% מ-200?",
  "choices": ["15", "30", "35", "20"], "correct": "b",
  "explanation": "10% מ-200 הם 20, ו-5% הם 10. ביחד: 30.",
  "verify": { "kind": "expr", "expr": "200*15/100" }
}
```

- `expr` תומך ב-`+ - * / ^` ובסוגריים. הערך של כל תשובה נלקח מהמספר הראשון שבטקסט שלה. לתשובות כמו שבר או שעה מוסיפים `value`, למשל `{ "text": "7/8", "value": 0.875 }`.
- בסדרות משתמשים ב-`{ "kind": "series", "rule": {...}, "start": [...], "shown": 4 }`. סוגי החוקיות מפורטים ב-`SeriesRule` שב-`types.ts`.
- ההסבר חייב להזכיר את התשובה הנכונה.

### הבנת הוראות (`instructions.json`)

קודם מוסיפים קטע ל-`passages`. הקטע כולל את הטקסט וגם גרסה פורמלית של החוקים ב-`spec`. אחר כך מוסיפים שאלות שמפנות אליו דרך `passageId`, עם `verify.query`. המשפחות האפשריות: `digit-code`, `letter-code`, `eligibility`, `procedure`, `robot`, `priority`, `assignment`. סוגי השאלות מפורטים ב-`InstructionQuery` שב-`types.ts`. הפותר נכשל אם התשובה לא חד-משמעית.

### מטריצות (`matrices.json`)

הכי פשוט לייצר אותן עם `scripts/gen-matrices.ts`. אפשר גם לכתוב `spec` ידנית: חוקיות לכל תכונה (`const`, `rowConst`, `colConst`, `latin`, `progression`, `sum`), יחד עם `seed` לבחירת המסיחים. הפותר מוודא שהמטריצה חד-משמעית.
