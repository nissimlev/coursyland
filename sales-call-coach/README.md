# מאמן שיחות מכירה

אפליקציית MVP ב-Python ו-Streamlit לתמלול שיחות מכירה בעברית וליצירת דוח אימון מכירות לפי תסריט קבוע.

## מה האפליקציה עושה

- העלאת קובץ אודיו מסוג `mp3`, `m4a`, `wav` ופורמטי אודיו נתמכים נוספים
- תמלול השיחה בעברית בעזרת OpenAI Audio API
- תיקון אוטומטי לקבצי אודיו עם סיומת תקינה אך קידוד פנימי בעייתי
- דחיסה אוטומטית של קבצי אודיו גדולים לפני שליחה לתמלול
- סידור התמלול לפי דוברים ושמות המשתתפים
- קריאת תסריט מכירה מתוך `sales_script.txt`
- קריאת שיטת ניתוח קבועה מתוך `sales_analysis_skill.txt`
- ניתוח השיחה בעזרת GPT
- בחירת מודל GPT מתוך האפליקציה לפני הניתוח
- הצגת התמלול והדוח במסך
- תיבת תמלול אחת שניתן לפתוח ולסגור
- דוח חד לפי סקיל מכירות: כשל מרכזי אחד, למה העסקה לא נסגרה, ציטוטים קריטיים, תגובה נכונה וסיכום מחץ
- מסך תובנות שמרכז 1-3 תובנות חדות מכל שיחה, ללא כפילויות
- שמירת דוח Markdown בתיקיית `reports`
- הורדת הדוח מהאפליקציה
- דוח אימון חד שמתחיל בכשלים מרכזיים, כולל ציטוטים מהשיחה, שאלות שלא נשאלו וניסוחים חלופיים
- מסך היסטוריית דוחות עם כרטיס לכל שיחה, צפייה, הורדה ומחיקה

## התקנה

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## הגדרת API Key

בפיתוח מקומי, צור קובץ `.env` בתיקיית הפרויקט:

```bash
OPENAI_API_KEY=your_api_key_here
```

ב-Streamlit Cloud, הגדר את המפתח דרך `Settings` -> `Secrets`:

```toml
OPENAI_API_KEY = "your_api_key_here"
```

אפשר להחליף מודלים דרך `.env`:

```bash
OPENAI_TRANSCRIPTION_MODEL=whisper-1
OPENAI_ANALYSIS_MODEL=gpt-5.4-mini
```

אפשר לבחור את מודל ה-GPT גם מתוך האפליקציה לפני ניתוח השיחה. הערך ב-`.env` הוא ברירת המחדל.

## תסריט המכירה

ערוך את הקובץ `sales_script.txt` והכנס אליו את תסריט המכירה שלך. האפליקציה תשתמש בו כבסיס לניתוח.

## שיטת הניתוח

שיטת הניתוח נשמרת בקובץ `sales_analysis_skill.txt`. אפשר לערוך אותו כדי לשנות את אופן הניתוח הקבוע של הדוחות.

## הרצה

```bash
streamlit run app.py
```

לאחר ההרצה, פתח את הכתובת ש-Streamlit מציג בטרמינל, בדרך כלל:

```text
http://localhost:8501
```

## פלט

כל דוח נשמר בתיקיית `reports` בשם הכולל תאריך ושם איש המכירות:

```text
reports/2026-06-11_14-30-00_ישראל_ישראלי.md
```

קובץ האודיו לא נשמר בפרויקט. הוא נקרא ישירות מההעלאה ונשלח לתמלול.

אפשר לראות דוחות קודמים באפליקציה דרך הטאב `היסטוריית דוחות`. כל דוח מוצג ככרטיס לפי שם הלקוח ותאריך השיחה, וניתן לפתוח, להוריד או למחוק אותו.

התובנות נשמרות מקומית בקובץ `reports/insights.json`. הקובץ מיועד לשימוש האפליקציה במסך `תובנות`, ולא נדרש לפתוח אותו ידנית.

## פתרון תקלות

- אם מופיעה שגיאה על `OPENAI_API_KEY`, ודא שהמפתח מוגדר ב-Streamlit Secrets או בקובץ `.env` מקומי.
- אם `sales_script.txt` ריק, מלא אותו בתסריט המכירה שלך.
- אם התמלול נכשל, בדוק שהקובץ תקין ושפורמט האודיו נתמך.
- אם הדוח לא נשמר, ודא שיש הרשאות כתיבה לתיקיית הפרויקט.
